# go-cache
`go-cache` is a very basic in-memory cache layer built in go. the main goal of this project is to learn a bit about caching and getting comfortable with go. the project is not meant to be used in production, it is purely educational.

# what to implement?
- [x] basic get/set/delete operations.
- [x] cache expiration and eviction policies.
- [x] support for concurrency.
- [x] metrics and monitoring.
- [x] access via HTTP API.
